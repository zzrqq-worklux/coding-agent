# opencode 安装器（便携版）使用教程

> 这份教程只讲“怎么用”，不讲复杂原理。你不需要懂电脑，照着做就行。

## 一、这个小工具能帮你做什么

**opencode 安装器（便携版）** 会帮你准备好三样东西：

1. **opencode**：一个会听你说话、帮你干活的电脑助手。
2. **邮件小助手**：帮你查看、整理、起草 Outlook 邮件。
3. **表格小助手**：帮你读取、汇总、修改 Excel 表格。

> **注意**：便携版**不包含做 PPT 的功能**。如果你需要做 PPT，请使用“厚重版”。

## 二、开始前，请准备好

- 一台 Windows 10 或 Windows 11 电脑。
- 能上网。
- 如果要用邮件小助手：电脑上已经安装并登录了**桌面版 Outlook**（不是网页邮箱）。
- 一个 DeepSeek 账号，以及一把“钥匙”。
- 大约 10～20 分钟时间。

### 什么是“钥匙”？

“钥匙”是一串很长的字符，通常以 `sk-` 开头。它就像你的会员卡，opencode 用它来使用 DeepSeek 的聪明大脑。钥匙只属于你，不要发给别人。

### 怎么拿到钥匙？

1. 打开浏览器，访问 `platform.deepseek.com`。
2. 注册或登录。
3. 找到 **API Keys** 这一项（可以理解成“钥匙管理”）。
4. 点击“创建”或“Create”，复制那串以 `sk-` 开头的字符。
5. 先粘贴到记事本里备用。

> **小提示**：钥匙通常只显示一次，复制后请保存好。如果丢了，可以重新创建一把。

### DeepSeek 怎么收费？

DeepSeek 按 token 用量扣费，不是包月。当前官方人民币价格（每百万 tokens，2026-11 查询）：

| 模型 / 时段 | 输入（缓存命中） | 输入（缓存未命中） | 输出 |
|---|---:|---:|---:|
| deepseek-flash · 空闲 | ¥0.02 | ¥1 | ¥4 |
| deepseek-flash · 高峰 | ¥0.04 | ¥2 | ¥8 |
| deepseek-v4-pro · 空闲 | ¥0.15 | ¥4.5 | ¥13.5 |
| deepseek-v4-pro · 高峰 | ¥0.30 | ¥9 | ¥27 |

日常做 PPT、邮件、表格，用 `deepseek-flash` 即可。一次 10 页 PPT 通常几毛到几块钱，具体取决于文件大小和对话轮数。

### 怎么注册和充值？

1. 打开 `platform.deepseek.com`，用手机号或微信扫码登录；没有账号会自动注册。
2. 按平台提示完成实名认证（如需要）。
3. 进入“充值”，用支付宝或微信充值。第一次可以先充 ¥10～¥50 试用。
4. 进入 **API Keys**，点击“创建”，复制 `sk-` 开头的 Key（只显示一次）。
5. 回到安装器，把 Key 粘贴进去。

> **价格可能调整**，请以官方价格页为准：`https://api-docs.deepseek.com/zh-cn/quick_start/pricing`

## 三、安装步骤（跟着做就行）

### 第 1 步：双击安装器

找到 `opencode安装器.exe`，双击它。

如果 Windows 弹出“Windows 已保护你的电脑”：

1. 点击“更多信息”。
2. 点击“仍要运行”。

> **不用担心**：这是因为安装器比较新，Windows 还不认识它。确认文件来自可信的人即可。

### 第 2 步：看黑色窗口，按提示走

安装器会打开一个黑色窗口，里面会出现中文提示。你不需要输入命令，只需要按提示按键。

**开始前建议先连接自己的手机热点。** 安装需要访问 GitHub、npm 和国内镜像，公司网络或代理可能拦截；如果确认公司网络可用，可以忽略。

**最简单的办法：看到不确定的提问，直接按回车。**

| 屏幕上出现 | 你按什么 |
|---|---|
| 是否继续 | 按回车 |
| 是否安装 | 按回车 |
| 是否安装 Python | 按回车 |
| 是否安装 PowerShell 7 | 按回车（建议安装；从 Git Bash 启动会自动跳过） |
| 请选择 | 按回车（使用推荐选项） |
| 是否立即启动 | 按回车 |

> 如果你按错了，也没关系。大部分问题都可以重新运行安装器再来一次。

### 第 3 步：粘贴 DeepSeek 钥匙

当窗口出现“请输入 DeepSeek API Key”时：

1. 把刚才复制的钥匙粘贴进去。在黑色窗口里可以点右键，或按 `Ctrl+V`。
2. 按回车。

> **正常现象**：粘贴后屏幕上可能看不到字符，这不是没输入，也不是电脑坏了。粘贴一次即可，不要重复粘贴。

### 第 4 步：选一个“聪明大脑”

窗口可能会让你选“模型”。你可以把它理解成“用哪个聪明大脑”。

屏幕上会标出“推荐”。**直接按回车，使用推荐的那个**即可。

### 第 5 步：选择要装的小助手

窗口会列出：

- Outlook 邮件助手
- Excel 表格助手

默认两个都选中。**直接按回车**，两个都会装好。

如果你只想要其中一个，可以输入前面的序号来取消勾选，再按回车。

### 第 6 步：等待安装

接下来安装器会自动下载和准备需要的文件。屏幕上会显示进度。

- 可能需要几分钟，取决于网速。
- **不要关闭黑色窗口。**
- 如果看到“正在安装 Python”，直接按回车同意即可。Python 是让表格小助手工作的一个零件，不用你操心。

### 第 7 步：完成

看到“OpenCode 安装完成”后：

- 如果问“是否立即启动 OpenCode？” → 按回车。
- 如果没启动，也没关系。以后打开一个黑色窗口，输入 `opencode`，按回车即可。

### 以后怎么打开 opencode？

1. 点击电脑左下角的“开始”。
2. 输入 `powershell`，打开出现的黑色窗口。
3. 输入 `opencode`，按回车。
4. 稍等一会儿，opencode 的界面就会打开。

> **桌面快捷方式**：安装器会自动在桌面创建 `OpenCode` 快捷方式。双击即可打开；把任意文件夹拖到快捷方式上，就会从该文件夹启动。

> 如果觉得每次这样打开麻烦，可以让给你安装器的人帮你做一个桌面图标。

## 四、第一次使用

打开 opencode 后，你会看到一个可以输入文字的窗口。**直接用平常说话的方式**告诉它你要做什么。

### 邮件小助手可以这样用

- “帮我看看今天收到的邮件，挑出最重要的三封，告诉我每封在说什么。”
- “帮我找一下上周客户发来的邮件。”
- “帮我给这个客户回一封信，语气客气一点，先给我看草稿，不要直接发。”

> 用邮件小助手前，请先打开桌面版 Outlook 并登录。它不能操作网页邮箱。

### 表格小助手可以这样用

- “把这个 Excel 表格里每个月的销售额汇总一下。”
- “帮我找出这个表格里重复的客户名字。”
- “把这张表里的空白行删掉，另存一份新的，不要改原文件。”

> 用表格小助手前，最好先关闭正在编辑的 Excel 文件，避免文件被占用。告诉它文件在哪里，或者把文件拖进对话窗口。

### 使用小原则

- 先说清楚你要什么，再让助手动手。
- 涉及发邮件、改文件、删数据时，先让它给你看方案，你确认后再执行。
- 不确定的操作，先问一句：“你打算怎么做？”

## 五、遇到问题怎么办

| 你看到的 | 可以这样做 |
|---|---|
| 双击没反应 | 再双击一次；如果被 Windows 拦住，点“更多信息”→“仍要运行” |
| 黑色窗口一闪就没了 | 重新双击安装器；先关闭安全软件的拦截提示再试 |
| 提示钥匙不对 | 检查是否复制完整（以 `sk-` 开头，没有空格）；确认账号里还有余额 |
| 邮件小助手不能用 | 打开桌面版 Outlook 并登录；确认不是网页邮箱；关掉再试 |
| 表格小助手不能用 | 先关闭 Excel 文件；换一个简单的表格文件试试 |
| 安装很慢 | 网络问题，耐心等；不要关闭窗口；可以换个时间再试 |
| 想更新 | 重新运行新版本的安装器，它会自动更新，原来的设置会保留 |
| 想卸载或换电脑 | 先不要自己删文件，联系给你安装器的人，帮你安全清理和迁移 |

## 六、安全与隐私

- 你的 DeepSeek 钥匙只保存在这台电脑上，不会发给别人。
- 不要把钥匙截图、复制或发给其他人。
- 助手只有在你的要求下才会读文件、改文件或发邮件。
- 涉及发送邮件、删除数据、覆盖文件时，先让它给你看草稿或计划，你同意后再做。

## 七、一页速查

1. 双击 `opencode安装器.exe`。
2. Windows 拦截 → “更多信息” → “仍要运行”。
3. 一路按回车；问钥匙时粘贴 `sk-` 开头的钥匙。
4. 聪明大脑和两个小助手都按回车，使用推荐选项。
5. 等待完成；问是否启动时按回车。
6. 以后打开黑色窗口，输入 `opencode` 回车。
7. 直接说人话：“帮我看看今天的邮件”“帮我汇总这个表格”。

> **便携版不含 PPT 功能。** 需要做 PPT，请使用厚重版。
