opencode 安装器（厚重版）使用教程

这份教程只讲“怎么用”，不讲复杂原理。你不需要懂电脑，照着做就能装好，也能做出第一份 PPT。

一、这个完整版能帮你做什么

opencode 安装器（厚重版） 会帮你准备好五样东西：

  1. opencode：一个会听你说话、帮你干活的电脑助手。
  2. PPT-Master：帮你做一份可以在 PowerPoint 里继续修改的 PPT。
  3. 归藏网页 PPT：帮你做一份可以在浏览器里全屏播放的网页 PPT。
  4. 邮件小助手：帮你查看、整理、起草 Outlook 邮件。
  5. 表格小助手：帮你读取、汇总、修改 Excel 表格。

和便携版的区别：厚重版多了两个做 PPT 的小助手，安装包更大，安装时间也更长。如果你只做邮件和表格，用便携版更轻快；如果你要做 PPT，就用这个厚重版。

二、开始前，请准备好

  • 一台 Windows 10 或 Windows 11 电脑。
  • 能上网。
  • 如果要用邮件小助手：电脑上已经安装并登录了桌面版 Outlook（不是网页邮箱）。
  • 一个 DeepSeek 账号，以及一把“钥匙”。
  • 大约 20～30 分钟时间（做 PPT 时可能更久）。
  • 如果准备做 PPT：把资料先放到一个文件夹里，比如 PDF、Word、提纲、图片。

什么是“钥匙”？

“钥匙”是一串很长的字符，通常以 sk- 开头。它就像你的会员卡，opencode 用它来使用 DeepSeek 的聪明大脑。钥匙只属于你，不要发给别人。

怎么拿到钥匙？

  1. 打开浏览器，访问 platform.deepseek.com。
  2. 注册或登录。
  3. 找到 API Keys 这一项（可以理解成“钥匙管理”）。
  4. 点击“创建”或“Create”，复制那串以 sk- 开头的字符。
  5. 先粘贴到记事本里备用。

小提示：钥匙通常只显示一次，复制后请保存好。如果丢了，可以重新创建一把。

怎么注册和充值？

  1. 打开 platform.deepseek.com，用手机号或微信扫码登录；没有账号会自动注册。
  2. 按平台提示完成实名认证（如需要）。
  3. 进入“充值”，用支付宝或微信充值。第一次可以先充 ¥10～¥50 试用。
  4. 进入 API Keys，点击“创建”，复制 sk- 开头的 Key（只显示一次）。
  5. 回到安装器，把 Key 粘贴进去。

价格可能调整，请以官方价格页为准：https://api-docs.deepseek.com/zh-cn/quick_start/pricing

三、安装步骤（跟着做就行）

第 1 步：双击安装器

找到 opencode安装器.exe，双击它。

如果 Windows 弹出“Windows 已保护你的电脑”：

  1. 点击“更多信息”。
  2. 点击“仍要运行”。

不用担心：这是因为安装器比较新，Windows 还不认识它。确认文件来自可信的人即可。

第 2 步：看黑色窗口，按提示走

安装器会打开一个黑色窗口，里面会出现中文提示。你不需要输入命令，只需要按提示按键。

开始前建议先连接自己的手机热点。 安装需要访问 GitHub、npm 和国内镜像，公司网络或代理可能拦截；如果确认公司网络可用，可以忽略。

最简单的办法：看到不确定的提问，直接按回车。

屏幕上出现 你按什么
是否继续 按回车
是否安装 按回车
是否安装 Python 按回车
是否安装 PowerShell 7 按回车（建议安装；从 Git Bash 启动会自动跳过）
请选择 按回车（使用推荐选项）
是否立即启动 按回车

如果你按错了，也没关系。大部分问题都可以重新运行安装器再来一次。

第 3 步：粘贴 DeepSeek 钥匙

当窗口出现“请输入 DeepSeek API Key”时：

  1. 把刚才复制的钥匙粘贴进去。在黑色窗口里可以点右键，或按 Ctrl+V。
  2. 按回车。

正常现象：粘贴后屏幕上可能看不到字符，这不是没输入，也不是电脑坏了。粘贴一次即可，不要重复粘贴。

第 4 步：选一个“聪明大脑”

窗口可能会让你选“模型”。你可以把它理解成“用哪个聪明大脑”。

屏幕上会标出“推荐”。直接按回车，使用推荐的那个即可。

第 5 步：选择要装的小助手

窗口会列出四个选项：

  • PPT-Master（做可修改的 PPT）
  • 归藏网页 PPT（做网页 PPT）
  • Outlook 邮件助手
  • Excel 表格助手

默认四个都选中。直接按回车，四个都会装好。

如果你只想要其中几个，可以输入前面的序号来取消勾选，再按回车。

建议第一次四个都装。以后想精简，可以重新运行安装器只选需要的。

第 6 步：等待安装

接下来安装器会自动下载和准备需要的文件。屏幕上会显示进度。

  • 厚重版比便携版大，可能需要几分钟到十几分钟。
  • 不要关闭黑色窗口。
  • 如果看到“正在安装 Python”，直接按回车同意即可。Python 是让 PPT 和表格小助手工作的一个零件，不用你操心。
  • 如果看到“正在安装 PPT 依赖”，也按回车同意，然后耐心等。它可能在准备做 PPT 需要的工具。

第 7 步：完成

看到“OpenCode 安装完成”后：

  • 如果问“是否立即启动 OpenCode？” → 按回车。
  • 如果没启动，也没关系。以后打开一个黑色窗口，输入 opencode，按回车即可。

以后怎么打开 opencode？

  1. 点击电脑左下角的“开始”。
  2. 输入 powershell，打开出现的黑色窗口。
  3. 输入 opencode，按回车。
  4. 稍等一会儿，opencode 的界面就会打开。

桌面快捷方式：安装器会自动在桌面创建 OpenCode 快捷方式。双击即可打开；把任意文件夹拖到快捷方式上，就会从该文件夹启动。

四、第一次做 PPT

做 PPT 和聊天一样，把资料和想法说清楚就行。下面按顺序来。

第 1 步：把资料放到一个文件夹

新建一个文件夹，比如“项目汇报”，把要用的 PDF、Word、提纲、图片都放进去。

第 2 步：在这个文件夹里打开黑色窗口

  1. 打开这个文件夹。
  2. 点击文件夹上方的地址栏。
  3. 输入 powershell，按回车。
  4. 会弹出一个黑色窗口，而且它已经在这个文件夹里了。

第 3 步：打开 opencode

在黑色窗口里输入 opencode，按回车。

第 4 步：告诉它你要做什么

你可以直接这样说：

  • “用这个文件夹里的 PDF 做一份 10 页的 PPT，重点讲项目背景、方案和预算。”
  • “把这份 Word 提纲做成一份可以在 PowerPoint 里继续修改的 PPT，风格简洁，蓝白色。”
  • “做一份分享风格的网页 PPT，10 页左右，适合在浏览器里全屏播放。”
  • “先别急着做，先给我一个 8 页的提纲，我确认后再生成。”

第 5 步：回答它的问题

它可能会问你：

  • 这份 PPT 给谁看？
  • 想要几页？
  • 想要什么风格或颜色？
  • 有没有公司模板？
  • 图片用文件夹里的，还是让它帮你找？

按你的想法回答即可。不确定就说“你推荐一个”。

第 6 步：等它做完

做 PPT 比聊天慢，可能需要几分钟。不要关掉窗口，也不要重复按回车。它做完会告诉你文件在哪里。

第 7 步：找到并打开文件

  • 如果它说“已保存”，文件通常就在你刚才打开的那个文件夹里。
  • 如果找不到，直接问它：“刚才生成的文件在哪里？”
  • PPT-Master 做出来的：是一个 PPT 文件，双击用 PowerPoint 打开，可以继续改文字、换图片、调颜色。
  • 归藏网页 PPT 做出来的：是一个网页文件，双击用浏览器打开，按方向键翻页；想全屏就点浏览器的全屏按钮。

做出更好 PPT 的小窍门

  • 先给它一个清楚的提纲，再让它生成。
  • 告诉它观众是谁、场合是什么、想要几页。
  • 给它公司模板或参考文件，做出来会更像你们公司的风格。
  • 一次做 8～12 页比较稳；太长的 PPT 可以分两次做。
  • 第一版不满意，直接说“第 3 页太挤了，帮我简化”“颜色再稳重一点”，它会继续改。

五、邮件和表格小助手

邮件小助手可以这样用

  • “帮我看看今天收到的邮件，挑出最重要的三封，告诉我每封在说什么。”
  • “帮我找一下上周客户发来的邮件。”
  • “帮我给这个客户回一封信，语气客气一点，先给我看草稿，不要直接发。”

用邮件小助手前，请先打开桌面版 Outlook 并登录。它不能操作网页邮箱。

表格小助手可以这样用

  • “把这个 Excel 表格里每个月的销售额汇总一下。”
  • “帮我找出这个表格里重复的客户名字。”
  • “把这张表里的空白行删掉，另存一份新的，不要改原文件。”

用表格小助手前，最好先关闭正在编辑的 Excel 文件，避免文件被占用。告诉它文件在哪里，或者把文件拖进对话窗口。

使用小原则

  • 先说清楚你要什么，再让助手动手。
  • 涉及发邮件、改文件、删数据时，先让它给你看方案，你确认后再执行。
  • 不确定的操作，先问一句：“你打算怎么做？”

七、安全与隐私

  • 你的 DeepSeek 钥匙只保存在这台电脑上，不会发给别人。
  • 不要把钥匙截图、复制或发给其他人。
  • 助手只有在你的要求下才会读文件、改文件或发邮件。
  • 涉及发送邮件、删除数据、覆盖文件时，先让它给你看草稿或计划，你同意后再做。
  • 做 PPT 时如果用到公司资料，先确认这些资料可以交给 AI 处理。

八、一页速查

  1. 双击 opencode安装器.exe。
  2. Windows 拦截 → “更多信息” → “仍要运行”。
  3. 一路按回车；问钥匙时粘贴 sk- 开头的钥匙。
  4. 聪明大脑和四个小助手都按回车，使用推荐选项。
  5. 等待完成；中途让装 Python 或 PPT 零件时按回车。
  6. 以后打开黑色窗口，输入 opencode 回车。
  7. 做 PPT：把资料放一个文件夹 → 在该文件夹打开黑色窗口 → 输入 opencode → 说“用这份 PDF 做一份 10 页 PPT”。
  8. 做邮件/表格：直接说人话：“帮我看看今天的邮件”“帮我汇总这个表格”。

厚重版包含两个做 PPT 的小助手。 只做邮件和表格，用便携版更轻快。

版本：厚重版 v4.2.0
适合：需要做 PPT、邮件、表格的同事和朋友
记住一句话：不确定就按回车；做 PPT 先说清楚“给谁看、几页、什么风格”。
